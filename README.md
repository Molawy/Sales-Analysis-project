### Sales Data Analysis Project 
#### This Project Focuses On Analyzing sales dataset using Python to Identify Trends and Patterns and Buisness Insights,Visualization
### ENVIRONMENT SETUP
#### This project uses CONDA for environment management and python 3.12
### 1- Create the conda environment
```bash
conda create -n Sales-project python=3.12
```
### 2- Activate the Environment
```bash
conda activate Sales-project
```
### 3- Install required Libraries
#### Install the dependencies listed in requirements.txt: 
```bash
pip install -r requirements.txt
```
### 4- Start and Run the project
#### Slect Sale-project Conda Environment as your python interpreter
